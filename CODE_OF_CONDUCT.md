# Code of Conduct

This project uses a simple community standard:

- Be respectful and constructive.
- Critique ideas and implementation, not people.
- Keep discussions relevant to SEO, GEO, AI search visibility, structured data, and Codex skill quality.
- Do not post harassment, hate speech, spam, private information, or intentionally misleading SEO advice.

Maintainers may close, hide, or remove comments, issues, pull requests, or discussions that violate these expectations.

## 中文

本專案採用簡明社群準則：

- 保持尊重與建設性。
- 批評想法與實作，不攻擊個人。
- 討論請聚焦於 SEO、GEO、AI 搜尋可見度、structured data 與 Codex skill 品質。
- 請勿張貼騷擾、仇恨言論、垃圾訊息、私人資訊，或刻意誤導的 SEO 建議。

維護者可關閉、隱藏或移除違反上述準則的 comments、issues、pull requests 或 discussions。
